# Ubiquitous language

This glossary defines the words MagicAIBuilder uses for its domain, one bounded context at a time.
Inside a context each term has exactly one meaning. Use these words, spelled this way, in code,
tests, comments, documentation, issues and pull requests. Where the product's user interface uses
a different word, the entry says so.

**How to read an entry.**

- **Meaning:** one or two sentences, in the domain's words.
- **Source:** the Comprehensive Rules (CR) number or the official source the meaning comes from.
  "Product" means the rule is MagicAIBuilder's own decision.
- **Code today:** the type, function or field that represents the term on `dev` at `872f08ff`
  (2026-11-10). Paths are under `src/` unless stated. Most code still lives in `lib/<area>/`; see
  [architecture.md](docs/engineering/architecture.md#how-to-read-the-code-base-today).
- **Mismatch:** the code name or behaviour disagrees with the domain term. Each mismatch is a
  candidate for a rename (a structural change) or a `fix/` pull request (a behaviour change).

**Rule sources.** CR numbers cite the Comprehensive Rules edition the app ships, effective
2026-08-07 (`src/lib/rules/data/MagicCompRules-20260807.txt`). Every number cited here was checked
against that file on 2026-11-10. The older copy in `docs/rules/` (effective 2026-02-27) is not the
reference.
Bracket and Game Changer facts come from
[the bracket guide](docs/product/guides/commander-deckbuilding-by-bracket.md) (bracket text of
2025-10-21) and [game-changers.md](docs/references/game-changers.md) (list of 2026-02-09); banlist
facts from [banlists.md](docs/references/banlists.md).

**Adding a term.** Add it in the same pull request that introduces it in code, under the context
that owns it, with its source. A new word for an existing concept is a rename, not a new term.

## Mismatches at a glance

| Term                                   | Domain says                                           | Code says                                                                           |
| -------------------------------------- | ----------------------------------------------------- | ----------------------------------------------------------------------------------- |
| [Bracket](#format-rules)               | Five brackets, 1 Exhibition to 5 cEDH                 | `BracketLevel = 1 \| 2 \| 3 \| 4`, bracket 1 named "Casual"; the API accepts 1 to 5 |
| [Basic land](#format-rules)            | Any land with the supertype "basic" (CR 205.4c)       | A type line containing "basic land", which misses "Basic Snow Land"                 |
| [Partner—Survivors](#format-rules)     | A partner ability of its own (CR 702.124i)            | No case: detected as plain `partner`                                                |
| [Partner with](#format-rules)          | Each card must name the other (CR 702.124j)           | `canPairWith` accepts any two "partner with" cards                                  |
| [Doctor's companion](#format-rules)    | Pairs only with a Time Lord Doctor (CR 702.124m)      | Pairs with any commander that has no pairing ability                                |
| [Companion](#format-rules)             | Starts outside the game (CR 702.139a)                 | Stored as a third command-zone slot                                                 |
| [Two-card combo](#format-rules)        | Game-enders, lockouts or infinites                    | Only infinite two-card combos are counted                                           |
| [Free multiplayer mulligan](#playtest) | Depends on the game: multiplayer or Brawl (CR 103.5c) | `FormatConfig.firstMulliganFree` means "played multiplayer by default"              |
| [Starting hand size](#playtest)        | Seven cards drawn before mulligans (CR 103.5)         | `OPENING_HAND_SIZE`; the CR's opening hand is the hand kept                         |
| [Phase and step](#playtest)            | Five phases, some split into steps (CR 500.1)         | `Phase` mixes steps (Untap, Upkeep, Draw) and phases                                |
| [Mana value](#deck-analysis)           | Mana value (CR 202.3)                                 | `cmc`, the obsolete "converted mana cost"                                           |
| [Maybeboard](#deck-building)           | "Considering" in the interface                        | `maybeboard` in code, plus two derived copies                                       |
| [Snapshot](#deck-building)             | One saved version of a decklist                       | "snapshot" in the deck panel, "version" in the playtest comparison                  |
| [Command slot](#deck-building)         | One concept                                           | Two `CommandSlot` types with different members                                      |
| [Card category](#deck-building)        | A role the player can change                          | One list mixes card types, roles and command-zone markers                           |
| [Highly rated](#community)             | Two different badges                                  | The deck badge and the player badge share the name `highly_rated`                   |
| [Model provider](#ai-copilot)          | One concept                                           | `anthropic`/`openai`/`mock` for suggestions, `ai`/`demo` for builds                 |
