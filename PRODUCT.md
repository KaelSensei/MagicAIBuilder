# Product Context

## Register

product

## Users

Magic: The Gathering players building, organizing, analyzing and playtesting decks through an international web interface.

## Product Purpose

Build, analyze, test and improve decks with reliable card data and focused AI assistance. The existing README documents collection management, deck editing, sharing and localized interfaces.

## Brand Personality

Reliable, focused and clear, following the purpose stated in the README. This maintenance task does not establish a new visual identity.

## Anti-references

Avoid automatic focus jumps, unnecessary mobile keyboard activation and dialog implementations that leave keyboard users interacting with the background.

## Design Principles

- Keep deck workflows usable without a mouse.
- Make focus movement follow an explicit user action.
- Preserve the surrounding application's established visual language.
- Make dismissal and error recovery predictable.

## Accessibility And Inclusion

Preserve keyboard navigation, focus visibility, dialog focus containment and focus restoration. Do not automatically focus search inputs when their surface opens. User feedback on 2026-10-11 permits visual adjustments for these corrections; a redesign is not required. No certification level is claimed.
