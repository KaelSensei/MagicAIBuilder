# Commander / EDH Themes & Archetypes

Complete catalog of deck themes recognized by the community (primarily sourced from EDHREC).
This list is essential for the assisted build mode: the user picks a theme and the engine filters cards accordingly.

**Source:** [EDHREC Themes](https://edhrec.com/tags/themes)

---

## Strategy Archetypes (How You Win)

| Theme | Description | Key Mechanics |
|-------|-------------|---------------|
| **Aggro** | Win fast through combat damage | Haste, pump spells, low curve |
| **Midrange** | Flexible value-based gameplan | Efficient creatures, removal, card advantage |
| **Control** | Answer everything, win late | Counterspells, board wipes, card draw |
| **Combo** | Assemble specific cards to win on the spot | Tutors, redundancy, protection |
| **Voltron** | Suit up one creature (usually commander), swing for lethal | Equipment, auras, protection, evasion |
| **Stax** | Slow opponents down with tax/lock effects | Tax effects, denial, resource disruption |
| **Pillowfort** | Discourage attacks, turtle up | Propaganda effects, damage prevention, fogs |
| **Group Hug** | Give everyone resources, win politically | Symmetrical draw/ramp, political cards |
| **Chaos** | Randomize the game state | Coin flips, random effects, theft |
| **cEDH** | Competitive EDH, playing to win at maximum efficiency | Fast mana, compact combos, free interaction |

| Theme | Description | Example Cards |
|-------|-------------|---------------|

| **-1/-1 Counters** | Weaken/kill creatures with counters | Hapatra, Nest of Scarabs, Black Sun's Zenith |

## Synergy Pairings (Common Theme Combinations)

These themes frequently combine and the builder should suggest complementary themes:

- **Tokens + Sacrifice** (make tokens, sac them for value)
- **Tokens + +1/+1 Counters** (go wide, then go tall)
- **Reanimator + Self-Mill** (fill graveyard, reanimate threats)
- **Aristocrats + Tokens** (make disposable creatures for sacrifice)
- **Spellslinger + Copy** (cast powerful spells, copy them)
- **Lifegain + Drain** (gain life, convert to damage)
- **Blink + ETB** (reuse enter-the-battlefield effects)
- **Artifacts + Treasure** (treasure ramp into artifact payoffs)
- **Enchantress + Voltron** (enchant commander, draw from auras)
- **Wheels + Discard** (force discards, punish from them)
- **Landfall + Extra Lands** (play extra lands per turn for triggers)
- **Counters + Proliferate** (place counters, multiply them)
