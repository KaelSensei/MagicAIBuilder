# Official Sources Index

Quick reference to all official and authoritative data sources.

## Rules & Legality

| Resource | URL | Usage |
|----------|-----|-------|
| Comprehensive Rules | https://magic.wizards.com/en/rules | Full game rules (PDF, TXT, DOCX) |
| Banned & Restricted List | https://magic.wizards.com/en/banned-restricted-list | All format banlists |
| Commander Official Banlist | https://mtgcommander.net/index.php/banned-list/ | Commander-specific bans |
| Game Changers (Scryfall) | https://scryfall.com/search?as=grid&order=color&q=is:gamechanger | Live Game Changers list |
| Banned in Commander (Scryfall) | https://scryfall.com/search?q=banned:commander | Live Commander banlist |

## Card Data & Search

| Resource | URL | Usage |
|----------|-----|-------|
| Scryfall API | https://api.scryfall.com | Card data, search, prices, legality, rulings |
| Scryfall Search | https://scryfall.com/advanced | Advanced card search UI |
| Scryfall Syntax Guide | https://scryfall.com/docs/syntax | Full search syntax reference |
| Card Images | https://cards.scryfall.io/ | High-res card images (normal, art_crop, border_crop, large, png) |

## Metagame & Statistics

| Resource | URL | Usage |
|----------|-----|-------|
| EDHREC | https://edhrec.com | Commander metagame stats, synergy/lift scores |
| EDHREC Themes | https://edhrec.com/tags/themes | All deck themes/archetypes |
| EDHREC Top Commanders | https://edhrec.com/top | Most popular commanders |
| Commander Spellbook | https://commanderspellbook.com | Combo database |
| MTGGoldfish | https://mtggoldfish.com | Price trends, metagame |
