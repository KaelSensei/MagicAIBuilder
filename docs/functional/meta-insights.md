## What the player can do

Everything lives in the builder page, once the deck has a commander. Two blocks read the wider
meta for that commander: the **Meta Analysis** panel and the **Meta shifts** trends view.
([User guide, Browsing decks for a commander](../product/user-guide.md#browsing-decks-for-a-commander))

**The Meta Analysis panel**, collapsed by default; nothing is fetched until it is opened.

- **See what other players run with this commander.** "Popular (EDHRec)" lists the twenty cards
  EDHREC reports with the highest inclusion for the commander, best first, each with a bar, its
  percentage ("78%") and, when EDHREC gives the counts, the sample ("36,079 / 46,229 decks").
- **See which of them the deck has or lacks.** A card already in the deck shows a green check; a
  card the deck lacks shows an add button, labelled "Add <name>", which adds it to the deck and turns
  into the check. The **Not in deck** filter hides the cards the deck already runs; when it hides
  them all, the section says "All popular cards already in your deck!".
- **See what moved in that list over time.** "Meta shifts" compares the oldest and newest EDHREC
  lists recorded for the commander in the last 90 days ("vs <date>") and shows up to eight
  movements: "+15 pts" or "-9 pts" for a card listed at both ends; "≥ +5 pts · New in the list" for
  a card that entered the top 20 and "≤ -12 pts · Out of the list" for one that left, with a hover
  note explaining that the value is a bound.
- **See recent tournament decks.** "Competitive (Tournaments)" lists up to five decks MTGTop8
  recorded for the commander, most recent first: placement badge ("#4"), deck name, pilot, event,
  date, and the format the site gives ("Duel Commander"). Each row opens the deck page on MTGTop8 in
  a new tab; the badge's hover shows the event's size as one to four stars.
- **Know where each number comes from and how old it is.** Under each section's title:
  "Source: EDHREC · Observed Nov 12, 2026" or "Source: MTGTop8 / MTGDecks · Observed …", with the
  evidence badge ("popular recommendations", "tournament observations"), and for the tournament
  section the span of the listed events ("Tournament evidence: May 5, 2024 – Jun 2, 2026").
- **Refresh.** The Refresh button at the top of the panel asks both sources again. For a
  moderator it goes back to EDHREC and MTGTop8; for everyone else it serves the shared day-old
  answer, and reads live only when there is no fresh answer yet.
- **Jump to the sources.** "Browse community decks for this commander" opens the site's own public
  decks for the commander; "View this commander on EDHRec" opens the commander's EDHREC page in a
  new tab.

**The Meta shifts view** sits beside the panel and shows, on its own, the five largest movements of
the same 90-day comparison, with the two snapshot dates, the badge "EDHREC top 20" and the sentence
that explains why an entry or an exit is a bound.

**The AI suggestions panel** (ai-copilot context) reuses two pieces: the evidence badge, which marks
its own suggestions "AI suggestions", and the freshness line ("Source: <provider> · Observed: <time>
· Deck snapshot: <n> cards").

## Who can do what

Both routes are public and read nothing about the visitor except for the refresh flag.

| Action                                                                                | Guest | Signed in | Owner | Moderator | API key scope                                        |
| ------------------------------------------------------------------------------------- | ----- | --------- | ----- | --------- | ---------------------------------------------------- |
| Open the panel, read the cards, shifts and decks                                      | yes   | yes       | yes   | yes       | none: `GET /api/meta/:slug` is public, 30/min per IP |
| Add a popular card to the deck (the builder's own add action; the deck's rules apply) | yes   | yes       | yes   | yes       | none: not a meta route                               |
| Press Refresh and be served the shared answer                                         | yes   | yes       | yes   | yes       | none                                                 |
| Force a new read of EDHREC and MTGTop8                                                | no    | no        | no    | yes       | none                                                 |
| Read the history                                                                      | yes   | yes       | yes   | yes       | none: `GET /api/meta/:slug/history`, 30/min per IP   |

## Not yet

- **A history that starts before the first visit.** Records grow from traffic only, so a commander
  nobody opened has no shifts, and the first two days of any commander show "No history yet" then
  "Recorded once so far". A scheduled crawl would need EDHREC's agreement and a job runner the app
  does not have ([I-67](../product/specs/i67-one-card-data-pipeline.md)).
- **Multiplayer tournament data.** MTGTop8's EDH section is mostly Duel Commander, and the panel
  says so per deck rather than filtering; a format picker and format-aware sources are
  [I-42](../product/specs/i42-commander-variants-duel-cedh-pauper.md).
- **The category a popular card came from.** EDHREC lists cards by role ("Lands", "Mana Artifacts",
  "New Cards"); the panel shows one flat top-20 list (pinned in `providers.replay.test.ts`; no B2 row).
- **A sample window from EDHREC.** The line says it is unavailable because the site publishes counts
  without the period they cover.
- **Card images in the list.** `MetaCard.imageUri` exists but no producer fills it.
- **High-synergy recommendations.** The evidence kind exists for the badge; nothing produces it.
- **Translated technical lines.** The freshness line under AI suggestions and the badge's
  accessible name are fixed English.
- **A refresh for signed-in members.** Only moderators bypass the day-old answer, to keep a public
  route from driving the scraping.
- **An off switch for the upstream calls** without a deploy
  ([I-69](../product/specs/i69-operator-console-support-moderation-and-kill-switches.md)).
- **A browser test of the panel.** The one Playwright spec (`e2e/mtgtop8-meta.spec.ts`) drives the
  tournament route against the live site and runs only when external tests are enabled; the panel
  itself is covered by the characterization suite, not by a browser.
